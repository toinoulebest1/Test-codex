# Test-codex

## Aperçu
Ce dépôt contient une landing page statique pour le service de streaming musical « WavePulse ».

## Lancer en local
```bash
python -m http.server 8000
```
Puis ouvrir `http://127.0.0.1:8000/`.

## Publication GitHub Pages
Si GitHub Pages est configuré pour publier le dossier `/docs`, le même fichier HTML est également
présent dans `docs/index.html`.
